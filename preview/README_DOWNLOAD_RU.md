# Скачать вымышленное демо v95

Если скачивание файла из чата не работает, скачайте
[safe-demo-v95.zip](safe-demo-v95.zip?raw=1) из этой ветки GitHub.

1. Найдите скачанный архив в папке «Загрузки».
2. Нажмите правой кнопкой → «Извлечь всё».
3. Откройте `index.html` из распакованной папки в браузере.

Логин и пароль не нужны. Все имена и операции вымышлены. Облако, отправка
обращений и платежи отключены; изменения остаются только в этом браузере.
Настоящие семейные файлы в демо не загружайте.

Это файл для локального просмотра на компьютере, а не установка обновления
рабочего банка. На телефоне локальный HTML может не открыться.

Источник приложения: коммит `eef6a1943e770ce1f555783bcdb830f10d038747`.
SHA-256 исходного `index.html`:
`307000d536d53f73a0bf9af4242133e7e6bcd9e7fcf1d74e5c309554a0c002f9`.
SHA-256 ZIP:
`0510ce50b2062d4f83f616dc198a4e3a42d0ab01f847af59e4acba9bfcb435b5`.

ZIP содержит только проверенную обезличенную сборку, её иконку и инструкции.
Личный установочный архив и серверные/устройственные резервы сюда не добавлялись.
