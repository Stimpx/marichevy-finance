# PR3 — финансовая целостность

Зависит от PR2; меняет только расчёты и пояснения, не банковский первичный график и не историю.

- Оплаченная часть рассрочки определяется текущей суммой связанной операции: уменьшение, удаление и переплата отражаются в остатке. Частично оплаченную операцию предлагается исправлять явно в истории, без автоматической замены.
- Для старого плана с неизвестным способом учёта перед первой новой оплатой требуется явный выбор: расходы по платежам либо покупка уже внесена целиком. Второй вариант создаёт погашение долга без нового расхода. Отмена ничего не меняет. Совпадение суммы 4 608 ₽ само по себе не удаляет и не связывает операции.
- Новая оплата получает сегодняшнюю фактическую дату и отдельную плановую дату. Просроченные неподтверждённые обязательства входят в прогноз; совпадение суммы/даты не используется как признак дубля.
- Сценарий досрочного погашения ограничивает взнос остатком тела, учитывает проценты при раннем закрытии, показывает неиспользованный излишек и прочие банковские начисления отдельно. При нулевом взносе сохраняется исходный график. Это оценка, а не банковская сумма закрытия.
- Советник использует месяцы с расходами; переводы и доходы без расходов не становятся базой потребления. Неполные доходы и ограничения сценария указаны явно.
- Распределение по получателям и фильтр истории используют единое определение назначения. Категория автомобиля/кредита не прибавляется повторно к получателям.

Проверки: 18 синтетических браузерных регрессий; на исходном e6befd6 воспроизведены 14 ошибок утверждений, на исправленном коде все 18 проходят. Проверены оба способа учёта рассрочки, нулевое/частичное/полное/избыточное досрочное погашение и оба сценария пересчёта. Новые устойчивые ID из PR2 сохранены. Настоящие операции, выписки, Supabase и Telegram не использовались.

Ограничения: полноту доходов приложение не может доказать по наличию записей. У регулярных планов нет достоверной даты начала, поэтому прошлые месяцы автоматически не достраиваются. Точный расчёт закрытия кредита и назначение неизвестных банковских сборов подтверждает банк; исходный график остаётся источником плановых сумм.
