# Как проверить подготовленную версию

**Ничего не опубликовано.** Демо содержит вымышленную семью и покупки. Вход, облако, Telegram и отправка обращений отключены. Настоящий аккаунт не нужен.

## Открыть демо

Скачайте `safe-demo.zip`, распакуйте архив и откройте находящийся внутри `index.html` в браузере. Не открывайте HTML прямо внутри окна архива. Все изменения демо сохраняются только в этом браузере на этом устройстве.

На телефоне открытие локального HTML может быть недоступно. В этом случае дождитесь отдельной безопасной HTTPS-ссылки предпросмотра. Не меняйте настройки рабочего банка и не переносите его настоящие данные ради демонстрации.

## Попробовать за несколько минут

1. Добавьте вымышленную покупку: сумма → что купили → для кого. Магазин можно оставить пустым. В «Деталях» проверьте дату, оплату и комментарий.
2. Перезагрузите страницу: запись должна остаться. Измените её сумму, затем удалите только эту учебную запись и снова перезагрузите.
3. В демо скачайте резервный JSON. Добавьте ещё одну учебную покупку, затем попробуйте импорт/восстановление именно этого тестового JSON и прочитайте сообщение о результате. Импорт может объединять записи: он не обязан удалять покупки, созданные после экспорта. Не очищайте хранилище для проверки отката.
4. Откройте главную, историю, аналитику, доходы, автомобиль, кредиты, цели, дела, даты и настройки. На компьютере и телефоне проверьте читаемость, выбор «Для кого», поиск покупки, кнопку сохранения и удобство прокрутки.

**Не загружайте в демо настоящий семейный JSON, чеки, контакты или снимки рабочего банка.** Для проверки используйте только вымышленные данные. Если браузер не сохраняет локальный файл после перезапуска, дождитесь HTTPS-предпросмотра.

## Что пока не готово к установке

Архив `personal-installation-PRIVATE.zip` — личный кандидат для закрытой проверки, **не готовое обновление рабочего банка**. Защищённую запись в облако ещё нужно отдельно проверить и включить на сервере; до этого новая версия оставляет изменения на устройстве. Наличие архива и успешные проверки интерфейса не подтверждают работу сервера. SQL-файлы в личном архиве предназначены для согласованной технической проверки, не для самостоятельного запуска.

Ссылка HTTPS ещё не опубликована. Для неё нужен отдельный изолированный адрес предпросмотра и согласованный доступ. Демо не требует доступа к рабочему банку.

## Резервная копия, обновление и возврат — только позже

Эти действия относятся к будущей установке, после отдельного согласования владельца и проверки сервера:

- Сначала скачайте JSON из действующего банка и убедитесь, что файл получен. Храните его лично. Отдельно сохраните прежние файлы сайта.
- Устанавливайте только согласованный кандидат по привычному доверенному способу. Не импортируйте семейную историю и не запускайте SQL как часть обычной замены страницы.
- При проблеме верните прежние файлы сайта. Не очищайте данные браузера и очередь несохранённых изменений. Восстановление JSON и изменения сервера требуют отдельного плана; замена страницы не отменяет уже записанные серверные данные.

Для обратной связи достаточно назвать экран, действие и ожидаемый результат. Скриншоты передавайте только из демо.
