# PR4 — ввод расхода на одном экране

Зависит от PR3. Структура согласована владельцем по макету; итоговый дизайн и выпуск ещё не утверждены.

Основные поля: сумма, поиск «Что купили», назначение «Для кого», видимый необязательный магазин. Дата по умолчанию сегодня; дата, способ оплаты, комментарий и уточнение доступны в деталях. Плательщик для расходов не возвращается; доходы и переводы сохраняют свой отдельный сценарий.

Поиск использует существующий словарь. Быстрые варианты ведут в прежние категории и уточнения: продукты, единые «Вкусняшки», школьное питание, английский, танцы, корм, подарок, ресторан, чаевые. Все остальные категории доступны через поиск и «Все категории». Дени и Макс выбираются отдельно. «Общее» — значение для новой покупки; старые назначения и неизвестные значения в редакторе сохраняются.

Убраны прежние конфликтующие правила только компонента ввода, включая повторные важные декларации. Новые стили ограничены формой и не добавляют `!important`; таблицы, транзакции, навигация и остальные разделы не переписывались. Общая адаптивная проверка выполняется на итоговой сборке.

7 браузерных тестов проверяют порядок/видимость полей, даты и назначения, контрольные варианты поиска, единые вкусняшки по людям без изменения истории, доходы/переводы, редактирование старых значений и размеры 1280/390/320. Все данные вымышленные; внешний доступ заблокирован. Скриншоты итоговой обезличенной сборки и общий регресс — в PR5.
