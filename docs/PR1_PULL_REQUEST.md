# PR1: защита локальных копий и безопасный импорт

Описание для **Draft Pull Request** из `codex/pr1-local-data-safety` в `main`. «PR1» — первый этап согласованного плана, не номер GitHub PR. Этот файл не подтверждает, что PR уже создан.

Повреждённая основная localStorage-копия раньше превращалась в пустое состояние, которое затем затирало резерв. Ошибки записи могли отображаться как сохранение, а ID импортированных записей попадали в исполняемый `onclick`. Исправления восстанавливают проверенные локальные копии, блокируют небезопасную перезапись и передают данные кнопок через JSON-атрибуты и фиксированные обработчики.

## Исправления

- Восстановление из корректной очереди или резервной копии; блокировка записи при отсутствии пригодного источника восстановления.
- Независимая резервная копия и сохранение повреждённых исходных байтов в карантине до их замены.
- Достоверные сообщения о сбоях основной записи и очереди; введённые значения формы не очищаются при ошибке.
- Проверка схемы JSON до импорта, обязательная копия для отката, откат памяти и локальных копий при ошибке фиксации.
- Устранение исполнения ID и аналогичных подстановок в списках операций, целей, дат, дел, сообщений, лимитов, регулярных планов и счетов.
- Изолированный локальный стенд: отключённый backend, ключи `marichevy_staging_*`, CSP `connect-src 'none'`, только loopback, без доступа к Git-файлам и методов изменения данных.

Формат JSON и production-ключи хранилища сохранены. Исторические категории и участники не ограничены списком; дополнительные поля операций и отсутствие `beneficiary` в старых записях сохраняются. Миграций и пересчёта истории нет.

## Оставшиеся риски и границы

- Квота, недоступность и очистка localStorage остаются ограничениями браузера. Резерв в том же браузере не заменяет внешний JSON-экспорт. Если все записи не удались, изменения остаются в памяти вкладки: её нельзя закрывать до сохранения копии.
- Гонки двух устройств, серверная версия, идемпотентность платежей и полноценная проверка облачного подтверждения остаются для PR2. Здесь исправлена только обработка ошибок локальных записей в существующих путях; протокол синхронизации не перерабатывался.
- Реальная история, Supabase/RLS, Telegram, серверная обратная связь, Safari и Яндекс Browser не проверялись этим набором.
- Структурно некорректный импорт отклоняется целиком. Настоящая история не удаляется и не переписывается в ходе разработки.
- Main, `finance.marichev.pro`, production, DNS, Cloudflare, Supabase, Telegram, финансовые расчёты и дизайн не изменялись. PR2–5 не начаты.
