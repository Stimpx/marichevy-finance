# Review artifacts — NOT PUBLISHED

`python tools/build_bundle.py --output-dir /workspace/artifacts` builds outside the repository. It never deploys, modifies the source HTML, reads browser data, or exports real operations. Run `python -m unittest discover -s tests -p test_build_bundle.py` for the narrow build checks.

- `safe-demo.zip`: fictional family, four example transactions, synthetic loan and dates; login bypassed only in generated demo. Original configured backend URL/key/household, Telegram IDs, account emails, family names and personal loan schedule are removed. Generic icon, strict file allowlist, no CNAME/private docs/Git. Namespace `marichevy_demo_*`; fixtures are created only when demo state/pending/recovery data are absent. Reload keeps browser edits. CSP exists in both HTML meta (including local-file opening) and `_headers`; early network guards block fetch, XHR, beacon, sockets, workers and sharing. Demo only stores locally. Integrations disabled. Local-file storage support varies by browser; a separately authorized HTTPS preview remains the simplest phone review path. A cloud localhost address is not an owner-accessible link.
- `personal-installation-PRIVATE.zip`: **private personal installation, never upload as a public demo**. Exact current repository `index.html`, original icons and existing CNAME, plus installation/backup/rollback instructions, server SQL and staging/activation warnings. The existing public client CONFIG is preserved. No session/environment credentials, database exports or tokens are added. This is an installation candidate, not a published release.
- `expense-proposal.html`, `mock-desktop.png` (1440px), `mock-mobile.png` (390px): compact expense-form proposal only. Primary fields: amount, purchase search, beneficiary, merchant. Additional details collapsed. Root app is unchanged by this mock. Reproducible HTML source: `tools/expense_proposal.html`.

Each ZIP uses sorted entries, fixed ZIP timestamps/permissions, SHA-256 `MANIFEST.json`, and `BUILD.json` recording the precise source SHA-256. Rebuilding identical source creates byte-identical ZIPs. Do not place output inside the checkout. The source transforms fail closed when expected CONFIG, family, Telegram or loan blocks disappear or duplicate; review generator and checks after source changes. Privacy checks cover known configured identities and source blocks; review any newly introduced personal constants before release.

Chromium validation performed in a fresh synthetic browser with every nonlocal request blocked: zero page errors, zero nonlocal requests, login gate hidden, four fixture entries; changed one fixture amount, reloaded, and observed the edited amount preserved. Only `marichevy_demo_*` browser keys were present. Desktop/mobile mock screenshots visually inspected. This local evidence does **not** prove production synchronization, Telegram delivery, RLS, or server deployment. Server sync guarantee remains pending its separate validation.

No merge or publication is authorized by producing these files. Before installation back up the live JSON and old static files; owner review and explicit production approval remain required.
