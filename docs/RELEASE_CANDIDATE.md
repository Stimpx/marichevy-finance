## Исправления этого продолжения

Трёхстороннее сравнение с подтверждённой серверной базой заменяет выбор по часам.
Основная локальная копия и pending также сравниваются с базой после частичного
сбоя записи. Неоднозначность блокирует отправку и сохраняет обе копии.
Отложенные refresh/login/verify ответы после logout не восстанавливают сессию.
Различные нерешённые серверные варианты архивируются; выгрузка включает
`previous_conflicts`, одинаковый повтор не наращивает архив. Вход дополнительно
проверяет доступ к настроенной семье до открытия кэша. Неизвестные поля дел и
прочие совместимые JSON-расширения сохраняются.

Конфликт не разрешается автоматически. Частный пакет через «Скачать варианты
конфликта» предназначен для согласования, не для обычного JSON-импорта. Полного
редактора конфликтов нет; семейные очереди нужно согласовать до перехода.
Пользователь браузерного профиля с доступом к его localStorage остаётся доверенным;
на общем компьютере нужны отдельные профили.

## Порядок конкретного выпуска после закрытия блокеров

- Зафиксировать выбранный commit и оба SHA выше, фактическую schema/migration,
  household revision, приватные резервные файлы и хеши. Проверить восстановление.
- Согласовать/сохранить очереди обоих устройств и остановить старые writers.
- Подготовить миграцию для фактической схемы, проверить preflight; при несовпадении
  не снимать guard и не заменять данные. Включение — только по явному одобрению.
- Установить сервер и клиент согласованно. Протокол 2 блокирует legacy-запись;
  до подтверждения контракта новый HTML не публиковать отдельно.
- После активации проверить основной домен, вход обоих участников, неизменённую
  историю, разрешённую настоящую правку и её появление после reload на втором
  устройстве; фиктивные траты в рабочую историю ради проверки не добавлять.
- При неуспехе остановить writers и сохранить новые данные/очереди. Статические
  файлы, протокол и JSON имеют отдельные планы возврата. Старый дамп не накатывать
  поверх новых операций. Переход 2→1 требует отдельного контроля и снимает CAS.
