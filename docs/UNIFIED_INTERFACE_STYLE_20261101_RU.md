# Единые шрифты, кнопки и действия операций · 1 ноября 2026

По образцу кнопки «Все даты» введено общее оформление команд: светлый фон,
тонкая синяя рамка, скругление 10px и спокойное начертание. Основные действия,
выбранные фильтры, удаление и недоступные команды сохраняют свои состояния.
Навигация, диаграммы, плитки направлений и календарные дни сохраняют оформление
своих компонентов. Общий стиль применяется и к динамическим формам/окнам.

Для всего приложения задан один системный sans-serif стек с поддержкой
кириллицы и без загрузки шрифта из внешнего сервиса. Введены общие роли:
обычный текст 400, подписи/команды 500, значения 600, заголовки 700. Выбранная
навигация и варианты могут иметь начертание 600. Иерархия размеров сохранена;
логотипы и изображения продавцов не изменены. Устранены локальные наборы
шрифтов и произвольные тяжёлые начертания обычного текста.

На главной, в истории, дневных операциях, доходах и расшифровках аналитики
изменение, повторение и удаление представлены общими линейными SVG-иконками.
В тех местах, где есть избранное, используется звезда. Области нажатия 44×44,
есть подсказки и доступные названия. Прежние обработчики, точные ID операций
и подтверждение удаления сохранены.

При увеличенном тексте исправлены перенос названий/сумм полос аналитики и
минимальная ширина сетки обратной связи. Рамка фокуса модального окна приведена
к общему синему стилю. Данные, расчёты, перенос остатка, сохранение изображений,
SQL и протокол синхронизации не меняются.
