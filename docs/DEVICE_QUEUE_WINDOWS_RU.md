# Полная очередь Windows без консоли браузера

Это отдельный локальный помощник для сохранения финансового Local Storage перед
установкой обновления. Он не публикует среду, не обновляет банк и не импортирует
данные. Обычные JSON владельца остаются отдельными копиями.

В запуске2 окно остаётся открытым после ошибки. Не запускайте файл прямо из ZIP:
нажмите ZIP правой кнопкой → «Извлечь всё» → «Извлечь». Если видите
«Нажмите любую клавишу», открыт прежний запуск. Причина первоначального отказа
на компьютере владельца пока не установлена. В последующем запуске2 владелец
показал успешный самотест и «СОХРАНЕНО» для используемого Chrome-профиля.
Файл также показан владельцем в отдельной папке Documents. Содержимое,
побайтовое совпадение скопированного файла и восстановление ещё не проверены.

1. Скачайте проверенный `preview/windows-private-backup-helper-v95-r2.zip` из
   закреплённого коммита кандидата. Распакуйте **весь архив** в новую локальную папку.
2. В используемом для банка профиле откройте `chrome://version` либо
   `browser://version` у Яндекса. Скопируйте полный «Путь к профилю».
3. Двойным щелчком откройте `Start backup.cmd`, вставьте этот путь.
4. Завершите ввод покупки, закройте Chrome и Яндекс через «Выход», включая чат.
   Нажмите Enter в окне помощника.
5. Сначала выполняется проверка на вымышленных данных. После успешного сохранения
   оставьте частный файл из `PRIVATE-backup-…` рядом с обычным JSON Windows.
   Открыть браузер снова можно. В чат сообщите только результат или код ошибки.

Не отправляйте файл в чат, Git, демо или staging. Не импортируйте его в банк.
Если Windows запрещает запуск, не отключайте защиту и не запускайте от
администратора. Консоль, `allow pasting`, расширения и PowerShell не нужны.

## Что проверено

На Linux проверены реальные синтетические LevelDB/Chromium, точные исходные строки,
удаления/устаревшие файлы, контрольные суммы, пределы размера, отсутствие сессий и
значений других сайтов в результате, неизменность источника. Контракты Windows API
проверены с подставленными API; настоящую Windows облако не запускало.
Обязательный встроенный тест использует настоящие Windows API до чтения профиля.
Успешный облачный тест ещё не подтверждает резерв владельца и его восстановление.

Исходный профиль открывается только для чтения. Движок работает с временной
частной копией под ACL пользователя+SYSTEM после независимой проверки целостности.
Общие файлы Local Storage временно содержат данные всех сайтов; декодируются и
экспортируются только разрешённые финансовые ключи банка. Временная копия удаляется
до записи результата. Подробности и ограничения — `tools/offline_queue/README_RU.txt`.

Архив содержит только программу, официальный Node.js, закреплённые зависимости
и вымышленный самотест. SHA-256:
`54bf8c5dd72deec6029edde888b05d259d8778548fd70cc28f6449d21c57a0df`.
Размер: 34 842 806 байт; 454 файла, manifest/CRC проверены.

Mac и iPhone сохраняются отдельно, из фактически используемого браузера/профиля
или PWA. Этот помощник их очереди не подтверждает. Несохранённый текст формы,
который ещё не попал в хранилище браузера, в файл не входит.
