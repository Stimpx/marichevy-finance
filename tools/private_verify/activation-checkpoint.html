Подготовка переключения банка

Выбери успешную папку сверки и свежий серверный резерв. Страница проверит, что серверный снимок совпадает с уже проверенным и восстановленным.

Файлы читаются локально. Сетевые соединения запрещены.

Сохрани подготовленные файлы в отдельную папку, рядом с папкой сверки.

Подготовка файлов не выполняет SQL и не устанавливает обновление. Сохрани служебные коды для чата; закрытые SQL и JSON оставь у себя. Исходные файлы не изменяются.
