Частная сверка копий банка · Mac · v95

Этот небольшой комплект дополняет уже работающую программу
mac-private-backup-helper-v95. Заново скачивать её не нужно.

1. Распакуй весь ZIP в отдельную папку mac-private-verification-v95
   рядом с папкой mac-private-backup-helper-v95, обычно в «Загрузках».
   Если копии приехали на флешке, сначала скопируй их в свою папку на Mac:
   выбирать файлы прямо с флешки не нужно.
2. Открой Start Mac verification.command.
3. Подтверди, что выбираешь копии своего рабочего банка finance.marichev.pro.
4. По очереди выбери семь файлов в открывающихся окнах:
   — серверную копию CSV или JSON из проверенного рабочего проекта Supabase;
   — обычный JSON и отдельную очередь Mac / Chrome;
   — обычный JSON и отдельную очередь iPhone / Safari;
   — обычный JSON и отдельную очередь Windows / рабочего браузера.
   Оба файла каждой пары должны относиться к одному и тому же профилю.
5. Дождись результата. В чат сообщи только «Результат» и «Коды».
   Сами файлы, отчёты, суммы, имена и пути в чат отправлять не нужно.

Файлы остаются на этом Mac. Оригиналы не изменяются. Частные копии, настоящий
результат локального восстановления и отчёты сохраняются в новой папке
PRIVATE-verification-… рядом с исходным помощником. Её оставь у себя.

Программа сравнивает записи и неизвестные поля, проверяет точные суммы и даты,
ссылки, сохранённые очереди, конфликты и контрольные суммы. Она не объединяет
варианты, не очищает очередь и ничего не импортирует в рабочий банк.

Локальное восстановление выполняется в памяти настоящего PostgreSQL 17.5 WASM
(PGlite 0.3.14): четыре таблицы приложения, внешние ключи, проверка RLS и репетиция
миграций. Для связей создаются только заглушки UUID пользователей. Полная учётная
система Supabase/Auth и платформа Supabase не восстанавливаются; параллельная
работа серверного PostgreSQL 16 этим запуском не проверяется. Сеть на время
локального восстановления запрещена. Установка PostgreSQL и Docker не нужна.

«passed» означает только успешную частную сверку и локальное восстановление
выбранных файлов. Это не разрешение обновлять рабочий сервер или публиковать
версию. При review_required или failed сохрани все варианты и сообщи коды.
Зелёная надпись синхронизации сама по себе не подтверждает отправку очереди.

Этот комплект ещё требует проверки на настоящем Mac владельца. Синтетические
проверки и запуск PostgreSQL WASM в облачной среде не заменяют эту проверку.

Если появится ошибка целостности, ничего не исправляй внутри комплекта и не
отключай защиту macOS. Не используй sudo и не меняй карантин/настройки Gatekeeper.
Профиль Chrome, пароли, сессии и сетевые секреты этой программе не нужны.
