ЧАСТНАЯ СВЕРКА БАНКА НА WINDOWS

1. Нажми ZIP правой кнопкой мыши → «Извлечь всё». Сохрани всю папку
   в «Загрузках» или «Документах» этого ноутбука. Из окна ZIP не запускай.
2. В распакованной папке открой «Start Windows verification.cmd».
   Установка Node, старый помощник и ввод путей не нужны.
3. Подтверди, что выбираешь копии своего рабочего банка finance.marichev.pro.
4. Последовательно выбери подготовленные файлы:
   1 — серверная копия CSV или JSON из рабочего проекта Supabase;
   2 — обычный JSON Mac / Chrome;
   3 — отдельная очередь того же профиля Mac / Chrome;
   4 — обычный JSON iPhone / Safari;
   5 — отдельная очередь той же вкладки iPhone / Safari;
   6 — обычный JSON Windows;
   7 — отдельная очередь того же профиля Windows.
   В каждом окне написаны номер и назначение файла. Переименование или копия
   одного файла не заменяют самостоятельную копию с нужного устройства.
   При повторном выборе можно исправить прежний пункт без перезапуска.
5. Дождись строк «Результат» и «Коды». В чат сообщи только эти строки.
   Самих файлов, содержимого отчёта и личных путей присылать не нужно.

Исходники читаются без изменения. Профиль браузера не открывается.
Выбранные копии и подробные отчёты сохраняются только на этом ноутбуке в новой
папке PRIVATE-verification-… рядом с программой; доступ — текущему пользователю
и системной службе Windows. Флешку можно использовать для выбора исходников,
но саму программу распакуй на локальный диск с поддержкой прав NTFS.

Результат passed означает успешную сверку и локальное восстановление четырёх
таблиц приложения в PostgreSQL WASM. Это не восстановление всей Supabase/Auth
и не автоматическая установка обновления. review_required сохраняет различия,
очереди и конфликты для разбора. Программа не импортирует данные в рабочий банк,
не очищает очередь и не меняет сервер. Новая проверка на настоящем Windows
остаётся необходимой; Linux-тесты не подтверждают работу системных диалогов.

Комплект предназначен для Windows x64. Не отключай защиту Windows, антивирус
или ограничения рабочего компьютера. При запрете запуска сообщи видимый код.
