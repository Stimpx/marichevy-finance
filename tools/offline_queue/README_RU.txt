ЧАСТНАЯ КОПИЯ БАНКА — Windows x64 · запуск 2

Это дополнительная копия финансового хранилища закрытого Chrome или Яндекс
Браузера. Она нужна перед обновлением банка, чтобы отдельно проверить
сохранённые записи, неотправленные правки и варианты конфликтов.
Это не новая версия сайта и не файл для самостоятельного импорта.

КАК ЗАПУСТИТЬ
Не открывайте Start backup.cmd прямо из окна ZIP. Нажмите ZIP правой кнопкой
мыши → «Извлечь всё» → «Извлечь». Откройте получившуюся обычную папку.
Рядом с Start backup.cmd должны быть папки app и runtime и файл MANIFEST.json.
Окно этой версии остаётся открытым после ошибки. «Нажмите любую клавишу»
она не показывает: если видите эту надпись, открыт прежний файл.

1. Сохраните обычный JSON из действующего банка. Не удаляйте прежние копии.
2. В том браузере и профиле, где заполняете банк, откройте chrome://version
   (Chrome) или browser://version (Яндекс). Скопируйте только значение строки
   «Путь к профилю». Если профилей несколько, для каждого нужна отдельная копия.
3. Распакуйте ВЕСЬ архив в новую обычную локальную папку на диске Windows.
   Не запускайте программу внутри ZIP. Сетевая папка или диск без ACL не подойдут.
4. Откройте «Start backup.cmd» двойным щелчком. Вставьте путь из шага 2.
   Вставьте полный путь к профилю из шага 2 — команды и пароли здесь не нужны.
5. Завершите ввод покупки. Полностью закройте Chrome и Яндекс Браузер через
   меню «Выход», включая вкладку чата. Затем нажмите Enter в окне помощника.
6. Сначала помощник проверит свои модули и блокировку на ВЫМЫШЛЕННЫХ данных.
   Только после успешной проверки он начнёт читать выбранное хранилище.
7. После «СОХРАНЕНО» появится путь к частному файлу в папке PRIVATE-backup-…
   внутри распакованного комплекта. Оставьте файл рядом с обычным JSON
   этого устройства. Можно снова открыть браузер и продолжать записи.
8. В чат напишите только «Очередь Windows сохранена» или показанный код ошибки.
   Сам файл и его содержимое оставьте у себя. Не импортируйте его в банк.

ЧТО ПРОИСХОДИТ
Исходное хранилище открывается только для чтения с проверкой закрытия браузеров
и блокировкой существующего LOCK. Движок базы работает только с временной
частной копией. Файлы проверяются до и после копирования; данные и настройки
исходного браузера не исправляются и не удаляются.

Хранилище Local Storage общее для сайтов: его файлы временно копируются в
закрытую папку текущего пользователя и SYSTEM. Помощник декодирует и сохраняет
только разрешённые финансовые ключи https://finance.marichev.pro. Пароли,
сессии входа и значения других сайтов не экспортируются. Временная копия
удаляется до сохранения итогового файла. Интернет программе не нужен;
сетевых запросов в ней нет. Это не сетевой изолятор операционной системы.

Проверяются исходные строки без округления чисел и удаления неизвестных полей.
Формат LevelDB поддерживается с отдельной проверкой контрольных сумм. Иной
формат, повреждение, изменившиеся файлы или отсутствие нужных ключей останавливают
копирование. Отсутствие ключей в одном профиле не означает пустую очередь другого.
Несохранённый текст открытой формы и состояние только в памяти не включены.

ОГРАНИЧЕНИЯ ПРОВЕРКИ
Этот комплект проверен в облаке на вымышленных данных, включая отдельные
контракты Windows API. Настоящие Windows API и установленный у владельца
браузер облако не запускало. Поэтому встроенная проверка на вашем Windows
обязательна и проходит до чтения настоящего профиля. Резерв устройства считается
подтверждённым только после успешного сохранения и отдельной проверки восстановления.
Это не полный резерв сервера, всех браузеров или всех устройств семьи.

Если Windows запрещает запуск, не отключайте защиту и не запускайте с правами
администратора. Остановитесь и сообщите текст ошибки без личных данных.
Если проверка не прошла, не очищайте хранилище и не переустанавливайте браузер.

ПРОИСХОЖДЕНИЕ
Переносимый Node.js 22.23.4 для Windows x64 — официальный nodejs.org;
SHA-256 архива и node.exe записаны в BUILD.json. Лицензия — runtime/NODE-LICENSE.txt.
Зависимости зафиксированы в app/package-lock.json. Их лицензии находятся
рядом с исходниками в app/node_modules. MANIFEST.json обнаруживает неполную
распаковку или изменение комплекта; это не электронная подпись.
