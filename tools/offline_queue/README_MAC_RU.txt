ЧАСТНАЯ КОПИЯ ОЧЕРЕДИ БАНКА — macOS / Apple Silicon и Intel

Это отдельная локальная программа. Код в консоль браузера вставлять не нужно.
Она не запрашивает пароль, токены, права администратора или отключение защиты.
Во время работы программа не обращается к интернету и не открывает браузер.

1. Скачайте только архив по закреплённой ссылке, которую дал сопровождающий.
   Распакуйте архив целиком в новую локальную папку своего пользователя.
   Не запускайте отдельный файл прямо из ZIP и не переносите только launcher.
2. В обычном профиле Chrome, где вы вносите траты, откройте chrome://version.
   Скопируйте значение строки «Путь к профилю» / Profile Path.
   Не угадывайте Default и не присылайте путь в чат.
3. Сохраните обычную резервную копию JSON через меню банка, если её ещё нет
   или после неё были новые правки. Исходные ранее сохранённые файлы оставьте.
4. Запустите Start Mac backup.command из распакованной папки.
   Если macOS блокирует запуск, сообщите сопровождающему точный текст.
   Не отключайте Gatekeeper, не удаляйте quarantine, не используйте sudo.
5. Вставьте путь к профилю в окно программы. Это имя папки, не команда.
   Затем полностью выйдите из Chrome через Chrome → Завершить Google Chrome.
   Это закроет и вкладку этого чата, если чат открыт в том же Chrome.
   После закрытия браузера вернитесь в окно помощника и нажмите Enter.
6. Сначала помощник обязан пройти встроенную проверку на вымышленных данных
   именно на этом Mac. При отказе ваши исходные файлы профиля не читаются.
   Облачные проверки и распознавание формата Mach-O не заменяют этот шаг.
7. Дождитесь сообщения «СОХРАНЕНО». Частный JSON будет в новой папке
   PRIVATE-backup-... внутри папки помощника. Файл можно хранить рядом
   с обычным экспортом именно этого профиля Mac. Самостоятельно импортировать
   его в банк не нужно. Содержимое и файл в чат не отправляйте.
8. Откройте Chrome снова. Достаточно сообщить «Очередь Mac сохранена»
   либо фиксированный код отказа. Получение файла не означает завершённую
   сверку с сервером и не означает, что обновление уже опубликовано.

Программа держит существующий LOCK исходной базы только на чтение и открывает
LevelDB engine только на временной закрытой копии. Проверка на вымышленных данных
отдельным процессом подтверждает, что блокировка не позволяет браузеру писать.
Сохраняются разрешённые финансовые ключи finance.marichev.pro; сессии входа
не декодируются и не включаются в итоговый JSON. Временная копия базы может
содержать другие сайты и остаётся закрытой до удаления помощником.
Не меняются исходные файлы, localStorage, настройки браузера или данные банка.

Этот ZIP содержит только код, зависимости и официальные Node.js runtimes.
Сверка MANIFEST.json обнаруживает повреждённые/изменённые файлы; она не является
цифровой подписью. Используйте именно предоставленную закреплённую ссылку.

При любом отказе исходный профиль не очищайте и самостоятельно не исправляйте.
Предыдущие копии оставьте отдельно. Помощник не перезаписывает старые резервы.
